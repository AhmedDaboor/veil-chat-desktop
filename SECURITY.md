# Reporting security issues

Veil Chat is pre-production and has not had an independent security audit. See [SECURITY_STATUS.md](SECURITY_STATUS.md) for verified controls and known limitations.

Please do not publish vulnerability details, exploit steps, access tokens, passwords, recovery material, or session data in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the **Security** tab to submit a private report. If it is unavailable, contact the repository maintainer privately through the maintainer's GitHub profile before sharing technical details.

There is no guaranteed response or remediation timeline. Do not use Veil Chat to protect sensitive communications until the documented release blockers have been resolved and independently verified.
